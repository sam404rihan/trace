# Calm Home Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Trace's crowded home with one next step (a topic drawing, one Continue button that resumes where you stopped), move the full course onto a `#/roadmap` page, quieten the sidebar, and give the whole app the warm, illustrated C3 look.

**Architecture:** Two new front-end files follow the existing `T.mountX(host, ctx)` pattern (`start.js`, `walkthrough.js`): `web/art.js` draws each topic's data structure as SVG, and `web/home.js` renders the home and roadmap from a context that `app.js` builds. `app.js` keeps all course state; it records "where you stopped" in local storage, works out the resume target, sets the page's stage colour, and routes `#/roadmap`. The look lives in `web/app.css` tokens, so every screen picks it up.

**Tech Stack:** Vanilla JS (no build step), CSS custom properties, inline SVG; Python stdlib server unchanged; headless-Chrome checks in `tests/browser/` (Node 22+).

**Spec:** `docs/superpowers/specs/2026-10-21-calm-home-design.md` (product truth: `PRODUCT.md`).

## Global Constraints

- Vanilla JS, HTML and CSS in `web/`; no build step, no new dependencies, no network at runtime.
- Keep the vendored faces: Schibsted Grotesk for text (heavier weights for headings), IBM Plex Mono for code only. No new font files.
- Drawings are SVG made by code; no image files.
- Every existing route keeps working; the only new route is `#/roadmap`.
- Nothing is removed, only tucked away: plans, the review drill, the starting check, reset, search and every topic stay reachable within two clicks of home.
- Home never shows lists, stats, or a second call to action competing with Continue.
- No cream-paper/serif/lamplight look, no gradients or blobs or stock icon tiles in place of a drawing.
- Real links and buttons, visible focus, headings in order; drawings are `aria-hidden` with the topic named in text.
- Light and dark both work (`prefers-color-scheme` and the theme toggle); white or dark text on a stage colour meets 4.5:1.
- Works at 390px wide with no horizontal scroll; respect `prefers-reduced-motion`.
- Load Impeccable's `reference/craft-floor.md` (base `C:/Users/sam/.claude/plugins/cache/impeccable/impeccable/4.1.2/skills/impeccable`) before the first UI edit.
- Commit messages end with the two attribution lines given in the session (Co-Authored-By and Claude-Session).

## Review Focus

1. A stored "last stop" that no longer resolves (a problem renamed or removed, a bad hash, storage blocked) must fall back to the course's next step without an error. Test: Task 3.
2. Everything finished (no `nextUp()`) must give a calm "finished" home and a roadmap whose current stage is the last one, not a blank page or a crash. Test: Task 4.
3. A study-plan last stop that is now solved must fall back to the topic path, not to the plan's next problem. Test: Task 3.
4. At phone width (390px) the hero stacks and nothing scrolls sideways. Test: Task 4.
5. In dark mode the hero's title and button stay readable on the stage colour (4.5:1). Test: Task 1 and Task 4.
